# data_seychelles – Seychelles FCAS dispatch model (EPM)

Hourly dispatch model of the Seychelles power system in 2035, used to find how much new thermal capacity Mahé needs
to hold the required fast frequency reserve (FCAS) in every hour, and at what cost. Results: [`results/`](results/).

- Two zones: **Mahe** and **PraslinLaDigue** (Praslin + La Digue), linked by the planned 40 MW Mahé–Praslin cable.
- Model year 2035, full chronology (8,760 hours, `fDispatchMode = 1`), no capacity expansion.
- Energy and reserve co-optimised; unit commitment on (minimum load, minimum up/down time, start-up cost).

> The CSVs are generated by `build_epm_inputs.py` (project scripts, not in this repository) from the unit list,
> hourly demand and solar/wind profiles. Change the builder or its sources and rebuild rather than editing by hand.

## Run

```bash
cd epm
python epm.py --folder_input data_seychelles                                   # Baseline (IRP fleet)
python epm.py --folder_input data_seychelles --scenarios --parallel 2 -S Base_U9 Islanded_U4
```

About 3–5 minutes per scenario (relaxed unit commitment, RMIP); run at most 2 in parallel on a 32 GB machine.
`config.csv` sets model type RMIP; `Baseline_MIP` runs full on/off commitment (`cplex/cplex_mip_sc.opt`: 1% gap,
1-hour limit).

## Scenarios (`scenarios.csv`)

| Scenario | Description |
|---|---|
| `Baseline` | IRP fleet (6 new 8 MW HFO units + 2.4 MW), cable in service, batteries at 80% |
| `Base_U<k>` | k new 8 MW HFO units (k = 2–20), cable in service, batteries at 80% |
| `BESS50_U<k>` | as Base, batteries counted at 50% of inverter MW (`supply/pStorageDataInput_BESS50.csv`) |
| `Islanded_U<k>` | no cable (`pSettings_Islanded.csv`), requirement two largest units (`reserve/pSpinningReserveReqCountry_Islanded.csv`) |
| `IslBESS50_U<k>` | no cable, batteries at 50% |
| `Baseline_MIP` | Baseline with full on/off unit commitment (MIP) |

The unit list for `_U<k>` is `supply/pGenDataInput_U<k>.csv` (k ≤ 6: new units removed; k > 6: copies of an 8 MW new
unit added).

## FCAS requirement and capability

| Item | Value |
|---|---|
| Requirement, Mahé (cable in service) | largest unit 8 MW + cable flow 40 MW (fixed) + 10% of hourly solar and wind output = 48 MW + VRE |
| Requirement, PLD (cable in service) | max(two largest units 4.5 MW, largest unit 2.5 MW + import from Mahé) + 10% VRE (`fApplyIntercoContingency = 1`) |
| Requirement, islanded | two largest units + 10% VRE: Mahé 16 MW, PLD 4.5 MW |
| Engines | units ≥ 6 MW (Mahé only), only while running, up to 20% of rated MW (1.6 MW per 8 MW engine), within headroom |
| Batteries | up to 80% (or 50%) of inverter MW; discharge + reserve ≤ inverter MW and ≤ energy stored at the start of the hour |
| No FCAS | engines < 6 MW (all PLD engines), waste-to-energy, solar, wind |
| Penalties | FCAS shortfall USD 500 per MW-h; unserved energy USD 1,000 per MWh (reserve is shed before load) |
| Cable | no reserve sharing between islands |

## Assumptions (2035)

| Item | Assumption | Source |
|---|---|---|
| Demand | Hourly IRP profile as provided (sum of nodes): Mahé 589.6 GWh / 96.2 MW peak; PLD 73.7 GWh / 12.8 MW | ECA IRP base case (no EV) |
| Rooftop PV | Excluded (demand treated as net of rooftop) | – |
| Mahé thermal | Victoria C A51/A61/B41/B51 (4 × 8 MW), extension (2 × 7.8 MW), new HFO 6 × 8 MW + 2.4 MW = 98 MW rated | PUC, ECA IRP; new unit size assumed |
| PLD thermal | Baie Ste Anne 5P (2.5), M6–M8 (3 × 1), new 4 × 2 MW, La Digue M9/M10 (2 × 0.65, back-up) = 14.8 MW | PUC, ECA |
| Waste-to-energy | 5 MW on Mahé | ECA IRP |
| Solar (rated) | Mahé 42.3 MW (Romainville 5.3, Providence 5, Mont Fleuri 8, Romainville North 5, Grand Anse 17, La Gogue 1, generic 1); PLD 29 MW | ECA IRP |
| Wind (rated) | Mahé 10 MW, PLD 70 MW | ECA IRP |
| Batteries | Mahé 35 MW / 70 MWh, PLD 40 MW / 81 MWh (2 h), efficiency 0.84 | ECA IRP |
| Availability | thermal and waste-to-energy 90%, solar and wind 95% of capacity in every hour; batteries 100% | Assumption |
| Engine operation | minimum load 30% of rated MW; min up/down 4/2 h (HFO), 2/1 h (LFO), 12/12 h (WtE); start-up USD 50/MW (WtE 100) | ECA Task 3 (min load); assumptions |
| Fuel | HFO 18.18, LFO 27.53 USD/MMBtu (2024 prices, flat); waste 0 | WB strategy note |
| Heat rate, VOM | per unit, e.g. Victoria C 8.73 MMBtu/MWh and USD 17/MWh, new HFO 8.73 and USD 1.4/MWh | ECA Task 3 / 4 |
| Solar profile | PVGIS-SARAH3, 2023; Romainville (Mahé), Baie Ste Anne (PLD) | PVGIS |
| Wind profile | Renewables.ninja, 2023, rescaled to capacity factor 10.8% (Mahé) / 14.1% (PLD) | PUC measured / ECA |
| Cable | 40 MW each direction, 2% losses | ECA IRP; losses assumed |

Modelling notes:
- Availability is a capacity derate; the engine FCAS share and minimum load are scaled so that an 8 MW engine
  (7.2 MW available) still gives 1.6 MW of FCAS and has a 2.4 MW minimum load. The contingency uses rated MW.
- All units are status 1 (existing) with their real start year; `RetrYr` is the last operating year.
- Rooftop and other solar units use tech `PV` (EPM's `RPV` tech has no hourly profile).
- `zcmap.csv` maps each island to its own "country" (SC_Mahe, SC_PLD) so that the reserve requirement is per island.

## Key settings (`pSettings.csv`)

| Setting | Value |
|---|---|
| `fDispatchMode` / `fEnableCapacityExpansion` | 1 / 0 |
| `fUseSimplifiedDemand` | 0 (hourly demand from `pDemandData`) |
| `fApplyCountrySpinReserveConstraint` / `fApplySystemSpinReserveConstraint` | 1 / 0 |
| `sVREForecastErrorPct` | 0.10 |
| `fApplyIntercoContingency` | 1 (largest unit + import; binds for PLD) |
| `fApplyMinGenCommitment` / `fApplyMUDT` / `fApplyStartupCost` / `fApplyRampConstraint` | 1 / 1 / 1 / 0 |
| `VoLL` / `SpinReserveVoLL` | 1,000 / 500 |
| `fEnableInternalExchange` (Islanded: 0) / `fAllowTransferExpansion` / `fEnableExternalExchange` | 1 / 0 / 0 |
| `fEnableStorage` / `InitialSOCforBattery` | 1 / 0.5 |
| `fApplyPlanningReserveConstraint` | 0 |

Files in `constraint/`, `h2/`, `trade/` (external trade) and `supply/` (CSP, capex trajectories) are placeholders
required by EPM; the corresponding features are switched off.

## Model changes on this branch (`epm/base.gms`, `epm/main.gms`, `epm/generate_report.gms`)

| Change | Purpose |
|---|---|
| `eSpinningReserveLimOnline`, `eJointResCapOnline` | Reserve only from running engines; output + reserve within committed capacity |
| `eStorInverterLimit`, `eStorEnergyHeadroom` | Battery charge + discharge share one inverter; discharge + reserve backed by energy stored at the start of the hour |
| `eStorageSOCInitDispatch` / `eStorageSOCFinalDispatch` | Battery level anchored only at the start and end of the year, with the first-hour balance applied |
| `mapAT`, `mapATprev`, `sWinUp`, `sWinDn` | Faster unit-commitment equations (same constraints, model build about 100× faster) |
| `eSpinningReserveReqIntercoTrip`, `fApplyIntercoContingency` | Reserve covers largest unit + imports (1) or N-2 + imports (2) |
| `pFCASPrice`; `pDispatchPlant` "Charge", "StateOfCharge" | Report: FCAS price (USD/MW-h); battery charging and state of charge |

All changes only act in dispatch mode with spinning reserve and unit commitment switched on.

## Limitations

- Relaxed unit commitment (LP): units can run partly on; key cases to be checked with full on/off commitment.
- The 40 MW cable contingency is applied in every hour, including hours when the cable carries less.
- Availability is a fixed derate, not random outages; N-2 is tested as fast reserve only.
- Demand shape is synthetic (no PUC hourly data); fuel prices flat; commitment parameters generic.
